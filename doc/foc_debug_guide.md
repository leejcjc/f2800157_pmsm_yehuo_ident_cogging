# FOC 调试原理详解

## 一、如何根据 iabc / idq / vdq 分析故障

### 核心逻辑链

FOC 电流环是一个**负反馈闭环**：

```
          ┌──────────────────────────────────────┐
          │                                      │
idRef ──(−)──→ [PI控制器] ──→ vDQ ──→ [逆Park+SVPWM] ──→ [电机] ──→ 实际电流
          ↑                                                           │
          └───── [Clarke+Park] ←── [ADC采样] ←────────────────────────┘
                     idq_fbk（反馈）
```

**负反馈的关键**：误差 = 参考值 - 反馈值，PI 根据误差调整输出，使反馈**趋近**参考值。

### 分析方法：看 vDQ 和 iDQ 的关系

#### 情况 1：正常

```
cmdTorque_A = 0.3
foc.iDQ.q  = 0.297   ← 跟随指令 ✅
foc.vDQ.q  = 0.289   ← PI 输出适中
foc.iDQ.d  = 0.01    ← 接近 0 ✅
```

**特征**：反馈 ≈ 参考，PI 输出稳定适中。

#### 情况 2：正反馈失控（传感器极性反）

```
cmdTorque_A = 0.3，但 idRef_d = 1.5（对齐阶段）
foc.iDQ.d  = 6.46    ← 远超参考值！
foc.vDQ.d  = +2.35   ← PI 还在加大输出！
```

**分析方法**：

| 观察 | 正常 | 正反馈 |
|---|---|---|
| iDQ vs 参考 | 接近 | 远超，且持续增大 |
| vDQ 方向 | 与误差同向（纠正） | 与电流同向（推波助澜） |
| 最终结果 | 稳定 | 过流保护 |

**怎么判断正反馈？**

关键公式：`误差 = 参考 - 反馈`

```
正常：
  参考 = 1.5A, 反馈 = 6.46A → 误差 = -4.96
  PI 应输出负值（减小电流）
  如果 vDQ.d 确实是负的 → 负反馈正常，只是来不及（瞬态过冲）

异常（传感器极性反的情况）：
  参考 = 0.3A, 反馈 = 6.46A → 误差 = -6.16
  PI 应输出负值
  但 vDQ.d = +2.35（正的！）→ 积分饱和，说明之前长期误差为正
  即：PI 长期以为电流不够 → 传感器极性反了
```

#### 情况 3：相序错误

```
foc.iDQ.d 和 iDQ.q 都在剧烈跳变
vDQ.d 和 vDQ.q 也在剧烈跳变
电机抖动或嗡嗡响
```

**特征**：d/q 轴解耦失败，电流在两个轴之间来回窜。

#### 快速诊断表

| 现象 | iDQ.d | iDQ.q | vDQ | 诊断 |
|---|---|---|---|---|
| 稳定跟随 | ≈ ref | ≈ ref | 适中 | ✅ 正常 |
| 电流飙升 + vDQ 同方向推 | 远超 ref | 远超 0 | 与电流同号 | ❌ 传感器极性反 |
| 电流飙升 + vDQ 反方向拉 | 远超 ref | | 与电流反号 | ⚠️ 瞬态过冲（增益太高或延迟太大）|
| d/q 都在跳 | 不稳定 | 不稳定 | 不稳定 | ❌ 相序错 / 角度错 |
| 电流始终 ≈ 0 | ≈ 0 | ≈ 0 | 饱和 | ❌ 驱动未使能 / 接线断 |

## 二、为什么要做开环测试

闭环系统出问题时，**反馈环路本身就是问题的一部分**，无法自诊断。

```
闭环调试的困境：
  电流飙升 → 是 PI 增益太大？传感器极性反？相序错？角度错？
  → 多个原因都能导致同一个现象
  → 无法区分
```

开环测试的目的是**打断反馈环路**，逐一排查：

```
开环：
  人为给定电压（固定 0.5V）→ 电机 → 观察电流
  没有 PI，没有积分饱和，没有失控风险
  电流是由物理定律（V = IR）唯一决定的
  → 只要看电流的符号和大小，就能确定传感器是否正确
```

**类比**：

- 闭环调试 = 开着车找发动机故障（车在跑，很多东西同时在变）
- 开环测试 = 熄火后手动转一下发动机看看（一次只检查一个东西）

## 三、开环测试的原理

### 我们做了什么

```c
foc.vDQ.d = 0.5f;    // 人为给定 d 轴电压
foc.vDQ.q = 0.0f;    // q 轴不施加
// θ = 0（强制电角度为 0）
```

### 物理上发生了什么

在 θ = 0 时，d 轴与 a 相对齐：

```
IPark(θ=0): Vα = Vd = 0.5V,  Vβ = Vq = 0V
```

SVPWM 将 Vα = 0.5V 转换为三相 PWM，最终效果等价于：

```
     ┌──── Rs ────┐
     │    0.18Ω    │
0.5V ──→ A相绕组 ──→ 星点 ──→ B+C绕组并联回地
                         │
                    Rs/2 = 0.09Ω
```

d 轴稳态电流：**Id = Vd / (1.5 × Rs) = 0.5 / 0.27 ≈ 1.85A**（理论值）

实测 0.66A 偏小，可能因为电机已锁定到某个位置有反电势分量，或 Rs 实际略大。

### 为什么看符号就能判断极性

```
因果链是确定的：

  +0.5V（d轴）→ 物理电流从 A 相流入 → ADC 读数应该增大

  如果 ADC 设计是：电流流入 → 读数 > 2048 → (读数-2048) > 0 → 正值
  那么：
    foc.iDQ.d 应该是正的

  如果 ADC 设计是：电流流入 → 读数 < 2048 → (读数-2048) < 0 → 负值
  那么：
    foc.iDQ.d 是负的 → 极性反了 → 需要取反
```

实测结果：

| | 取反前 | 取反后 |
|---|---|---|
| foc.iDQ.d | **-0.68** ❌ | **+0.66** ✅ |

**开环测试只需一次，就能确定性地诊断出极性问题**，而闭环下可能花很长时间反复猜测。

## 总结

| 问题 | 答案 |
|---|---|
| 如何分析 iabc/idq/vdq | 看 vDQ 是在**纠正**还是在**推波助澜**电流 |
| 为什么开环测试 | 打断反馈环，消除 PI 干扰，单独验证硬件 |
| 开环原理 | 已知输入(+0.5V) → 已知因果(欧姆定律) → 看输出符号判断极性 |
