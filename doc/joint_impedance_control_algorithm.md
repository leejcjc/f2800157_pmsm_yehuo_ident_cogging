# 关节电机阻抗控制算法详细说明

> **硬件平台**: TMS320F2800157 @ 120MHz + 野火直流无刷驱动板 + 42JSF630AS-1000  
> **电机参数**: 50极对, Rs=1.02Ω, Ld=Lq=0.59mH, 额定4A/0.2Nm, 1000线增量编码器  
> **控制框图**: 见 `joint_control_block_diagram.drawio`

---

## 一、整体架构概述

本算法采用**三层嵌套控制架构**，由外到内分别为：

| 层次 | 名称 | 执行频率 | 核心任务 |
|------|------|----------|----------|
| 第一层 | 阻抗控制器 | 1.5 kHz | 根据目标位置和刚度/阻尼参数，计算期望力矩 τ_desired |
| 第二层 | 力矩→电流换算 + 前馈补偿 | 1.5 kHz | 将 τ_desired 转换为电流环参考值 Iq_ref，并叠加摩擦和齿槽补偿 |
| 第三层 | FOC 电流环 | 15 kHz | 标准 Id=0 矢量控制，跟踪 Iq_ref，输出 SVPWM 驱动电机 |

三层共用**同一个编码器**作为反馈源，编码器信号分三路使用：电角度 θe（电流环）、机械角度 θm（阻抗控制器）、转速 ω（阻抗控制器+摩擦补偿）。

**与传统 PID 位置控制的本质区别**：传统位置环的目标是"不管怎样都到达目标位置"，碰到障碍会疯狂加大电流；阻抗控制的目标是"像弹簧一样运动"，碰到障碍自然退让，实现安全柔顺交互。

## 二、第一层 — 阻抗控制器 (1.5 kHz)

### 2.1 基本原理

阻抗控制器让关节的动态行为等效为一个**可调参数的弹簧-阻尼系统**：

$$
\tau_{desired} = K_p \cdot (\theta_d - \theta_m) + K_d \cdot (\omega_d - \omega)
$$

其中：
- **θ_d** — 目标位置（rad），由上位机或调试器给定
- **θm** — 实际机械角度（rad），编码器反馈
- **Kp** — 虚拟刚度（Nm/rad），决定关节"硬度"
- **Kd** — 虚拟阻尼（Nm·s/rad），决定关节阻尼特性
- **ω_d** — 目标角速度（rad/s），通常设为 0
- **ω** — 实际角速度（rad/s），编码器差分计算

### 2.2 Kp 和 Kd 的物理意义

| 参数组合 | 行为 | 应用场景 |
|----------|------|----------|
| Kp 很大, Kd 适中 | 关节很"硬"，快速跟踪目标位置 | 等效于高增益位置控制 |
| Kp 适中, Kd 适中 | 关节有弹性，碰到障碍会柔顺退让 | 人机协作、拖动示教 |
| Kp = 0, 直接给 τ_desired | 纯力矩模式，完全顺从外力 | 力控打磨、装配 |
| Kp 小, Kd 大 | 关节像在粘稠液体中运动 | 阻尼运动、重力补偿 |

### 2.3 执行频率选择

阻抗控制器处于力学层面，受控对象是电机转子惯量（机械系统）。机械系统的响应带宽远低于电气系统，因此 **1.5 kHz**（15kHz ISR 的 10:1 分频）已经足够。更高频率不会改善性能，反而增加 CPU 负担。

### 2.4 输入/输出

```
输入:
  - θ_d, ω_d      ← 用户指令（上位机/调试器）
  - Kp, Kd         ← 用户指令（可在线调节）
  - θm, ω          ← 编码器反馈

输出:
  - τ_desired (Nm) ← 传递给第二层
```

## 三、第二层 — 力矩→电流换算 + 前馈补偿 (1.5 kHz)

### 3.1 基本换算

电机力矩与 q 轴电流的关系：

$$
\tau = K_t \cdot I_q
$$

其中 Kt 为力矩常数（Nm/A）。因此基础电流参考值为：

$$
I_{q,base} = \frac{\tau_{desired}}{K_t}
$$

**问题**：这只是理想值。实际电机存在摩擦和齿槽效应，导致真实输出力矩与命令值有偏差。由于我们没有力矩传感器，无法闭环修正，因此采用**前馈补偿**策略。

### 3.2 摩擦前馈补偿 — Stribeck 模型

减速器、轴承和电机本身都有摩擦。摩擦力矩在低速时尤其显著，会导致电机卡顿和力矩输出不线性。

**Stribeck 摩擦模型**：

$$
\tau_{friction} = sign(\omega) \cdot \left[ \tau_c + (\tau_s - \tau_c) \cdot e^{-(\omega/\omega_s)^2} \right] + B \cdot \omega
$$

其中：
- **τ_c** — 库仑摩擦力矩（与速度方向有关的恒定摩擦）
- **τ_s** — 静摩擦力矩（从静止开始运动时需要克服的最大摩擦）
- **ω_s** — Stribeck 速度（从静摩擦过渡到库仑摩擦的特征速度）
- **B** — 粘性摩擦系数（与速度成正比的摩擦）

**参数辨识方法**：
1. 让电机在不同恒定转速下运行（如 10, 50, 100, 200, 500, 1000 rpm）
2. 记录每个速度下的稳态 Iq 值
3. 用最小二乘法拟合上述公式的 4 个参数

**运行时补偿**：根据当前转速 ω 实时计算 τ_friction，加到 Iq_ref 上。

### 3.3 齿槽力矩补偿 — 离线标定查表

永磁体和定子齿槽的相互作用产生周期性力矩脉动，频率为电角度的整数倍（主要是 6 次和 12 次谐波）。

**标定方法**：
1. 让电机极低速匀速旋转（如 5 rpm）
2. 记录 Iq 随电角度 θe 的波动曲线
3. 减去平均值，得到齿槽力矩表 g(θe)

**两种实现方式**：

方式 A — 查表法：
```
将一个电周期（0~2π）等分为 N 个点（如 256 点），
存储对应的补偿电流值。运行时根据当前 θe 线性插值查表。
```

方式 B — 傅里叶分解法：
```
g(θe) = A6·sin(6θe + φ6) + A12·sin(12θe + φ12) + ...
只需存储几个谐波的幅值和相位，计算量更小。
```

### 3.4 最终 Iq_ref 合成

$$
I_{q,ref} = \frac{\tau_{desired}}{K_t} + \frac{\tau_{friction}(\omega)}{K_t} + I_{cogging}(\theta_e)
$$

### 3.5 输入/输出

```
输入:
  - τ_desired      ← 来自第一层
  - ω              ← 编码器反馈（用于摩擦补偿）
  - θe             ← 编码器反馈（用于齿槽补偿）
  - Kt             ← 电机参数（常数）

输出:
  - Iq_ref (A)     ← 传递给第三层电流环
```

## 四、第三层 — FOC 电流环 (15 kHz)

### 4.1 控制目标

使电机的 d 轴电流 Id 维持在 0（最大转矩电流比），q 轴电流 Iq 跟踪上层给定的 Iq_ref。

### 4.2 信号处理流程

#### 步骤 1: 电流采样
- ADC 采集两相电流 Ia、Ib（三电阻采样，ePWM 谷底触发）
- 减去偏置校准值，得到真实电流

#### 步骤 2: Clarke 变换 (abc → αβ)

$$
I_\alpha = I_a
$$
$$
I_\beta = \frac{1}{\sqrt{3}} (I_a + 2 I_b)
$$

将三相静止坐标系电流转换为两相静止坐标系。

#### 步骤 3: Park 变换 (αβ → dq)

$$
I_d = I_\alpha \cos\theta_e + I_\beta \sin\theta_e
$$
$$
I_q = -I_\alpha \sin\theta_e + I_\beta \cos\theta_e
$$

将静止坐标系电流旋转到与转子磁场同步的旋转坐标系。**θe 来自编码器**。

#### 步骤 4: PI 控制器

d 轴 PI 控制器：
```
Vd = Kp_d × (Id_ref - Id) + Ki_d × ∫(Id_ref - Id)dt
其中 Id_ref = 0
```

q 轴 PI 控制器：
```
Vq = Kp_q × (Iq_ref - Iq) + Ki_q × ∫(Iq_ref - Iq)dt
其中 Iq_ref 来自第二层
```

PI 参数设计依据：
- Kp = Ls × 带宽 (rad/s)
- Ki = Rs × 带宽 (rad/s)
- 典型电流环带宽: 500~2000 Hz

#### 步骤 5: 反 Park 变换 (dq → αβ)

$$
V_\alpha = V_d \cos\theta_e - V_q \sin\theta_e
$$
$$
V_\beta = V_d \sin\theta_e + V_q \cos\theta_e
$$

#### 步骤 6: SVPWM (空间矢量调制)

将 Vα、Vβ 转换为三路 PWM 占空比，驱动逆变器的 6 个 MOSFET。

### 4.3 执行频率选择

电流环频率 = PWM 频率 = **15 kHz**。由 ePWM1 的 SOCA 事件在计数器谷底触发 ADC 采样，ADC 完成后触发 ISR 执行整个电流环。

## 五、传感器反馈 — 一个编码器的三重用途

### 5.1 硬件

1000 线增量式光电编码器，通过 eQEP1 模块 4 倍频解码，得到 **4000 counts/rev**。

### 5.2 三路信号提取

#### (1) 电角度 θe — 给电流环

```
counts_per_elec_cycle = 4000 / 50 = 80
θe = (QPOSCNT % 80) × (2π / 80)
```

50 极对意味着机械转一圈有 50 个电周期，每个电周期对应 80 个编码器计数。

**用途**: Park 变换、反 Park 变换、齿槽补偿查表

#### (2) 机械角度 θm — 给阻抗控制器

```
θm = QPOSCNT × (2π / 4000)  (单圈)
θm_total = turn_count × 2π + θm  (多圈累计)
```

需要在 Index 脉冲或 QPOSCNT 溢出时累加圈数，实现连续位置跟踪。

**用途**: 阻抗控制器的位置误差计算 (θ_d - θm)

#### (3) 转速 ω — 给阻抗控制器 + 摩擦补偿

```
ω = (QPOSCNT_new - QPOSCNT_old) / Δt × (2π / 4000)  (rad/s)
```

使用 eQEP 的 Unit Timer（1ms 周期）计算速度，或在 ISR 中差分计算。

**用途**: 阻抗控制器的阻尼项 Kd·(ω_d - ω)、摩擦前馈模型 f(ω)

### 5.3 为什么一个编码器就够

本方案采用**直驱**（无减速器），电机轴就是输出轴，因此：
- 不存在减速器回差问题
- 输入端位置 = 输出端位置
- 一个编码器同时满足电流环（需要电角度）和阻抗控制器（需要机械角度和速度）的需求

如果加了减速器，则需要两个编码器：输入端给电流环算电角度，输出端给阻抗控制器算真实输出位置。

## 六、ISR 执行流程

每次 ADC 中断（15 kHz）进入 ISR 后的执行顺序：

```
motorControlISR() @ 15 kHz:
│
├── 1. 读 ADC: Ia, Ib, Vdc
├── 2. 减偏置: Ia -= offset, Ib -= offset
├── 3. 读编码器: QPOSCNT → θe, θm, ω
├── 4. Clarke: Ia,Ib → Iα,Iβ
├── 5. Park: Iα,Iβ,θe → Id,Iq
│
├── 6. 每 10 次执行一次 (1.5 kHz):
│   ├── 6a. 阻抗控制器: τ = Kp·(θd-θm) + Kd·(ωd-ω)
│   ├── 6b. 力矩换算: Iq_base = τ / Kt
│   ├── 6c. 摩擦前馈: Iq_fric = f(ω) / Kt
│   ├── 6d. 齿槽补偿: Iq_cog = g(θe)
│   └── 6e. 合成: Iq_ref = Iq_base + Iq_fric + Iq_cog
│
├── 7. PI_d: Vd = PI(0 - Id)
├── 8. PI_q: Vq = PI(Iq_ref - Iq)
├── 9. 反Park: Vd,Vq,θe → Vα,Vβ
├── 10. SVPWM: Vα,Vβ → PWM_A, PWM_B, PWM_C
├── 11. 写 PWM 占空比
├── 12. 故障检测 (过流/过压)
└── 13. 清中断标志, 返回
```

## 七、关键设计参数

### 7.1 系统时钟与频率

| 参数 | 值 |
|------|-----|
| CPU 主频 | 120 MHz |
| PWM 频率 | 15 kHz (中心对齐) |
| ISR 频率 | 15 kHz |
| 电流环频率 | 15 kHz |
| 阻抗/补偿层频率 | 1.5 kHz (10:1 分频) |
| eQEP 测速周期 | 1 ms |

### 7.2 电流环 PI 参数（参考值）

| 参数 | 公式 | 参考值 |
|------|------|--------|
| Kp_d = Kp_q | Ls × 2π × BW | 0.59mH × 2π × 1000 = 3.71 |
| Ki_d = Ki_q | Rs × 2π × BW | 1.02 × 2π × 1000 = 6409 |

其中 BW 为电流环带宽，典型取 800~1500 Hz。

### 7.3 阻抗控制参数（初始调试参考）

| 参数 | 初始值 | 说明 |
|------|--------|------|
| Kp | 0.1 Nm/rad | 先设小值，逐步增大 |
| Kd | 0.005 Nm·s/rad | 提供阻尼，防止振荡 |

## 八、实施步骤建议

### 阶段 1: FOC 电流环验证
- 开环给定 Iq_ref（如 1A），验证电流环跟踪性能
- 测量电流环带宽和阶跃响应
- 确认编码器电角度对齐正确

### 阶段 2: 速度环验证
- 在电流环基础上加速度环 PI
- 验证速度跟踪、加减速性能

### 阶段 3: 摩擦辨识
- 不同恒定速度下记录稳态 Iq
- 拟合 Stribeck 模型 4 个参数

### 阶段 4: 齿槽力矩标定
- 极低速匀速运行，记录 Iq vs θe
- 生成补偿查表或傅里叶系数

### 阶段 5: 阻抗控制集成
- 用阻抗控制器替代速度/位置环
- 从小 Kp 开始调试
- 验证柔顺交互效果

### 阶段 6: 综合验证
- 在线调节 Kp/Kd，验证不同刚度/阻尼下的行为
- 手动施加外力，验证柔顺回弹
- 记录实测数据用于简历和面试展示

## 九、与传统三闭环的对比

| 维度 | 传统 PID 三闭环 | 阻抗控制方案 |
|------|-----------------|--------------|
| 最外环目标 | 位置精度 | 力矩精度 + 柔顺性 |
| 碰撞响应 | 硬停（过流保护） | 柔顺退让（弹簧行为） |
| 参数意义 | PID 增益（抽象） | 刚度/阻尼（物理直觉） |
| 力矩纹波 | 可接受 | 必须补偿（影响柔顺质感） |
| 模式切换 | 需要不同控制器 | 调 Kp/Kd 即可覆盖多种模式 |
| 应用场景 | 伺服定位、CNC | 机器人关节、人机协作 |
